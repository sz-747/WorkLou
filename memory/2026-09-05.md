# WorkLou Session Memory

## Decisions

- Compare three starting models in the first Paper batch: next-task first, woman first, and guided-session first. This isolates the main navigation choice while keeping the visual language stable.
- Use a separate urgent path for crisis accommodation: direct call and daily retry. Keep email and a five-day follow-up for routine referrals.
- Keep woman-stated information, worker observations, and provider confirmations distinct because they carry different authority.
- Keep the prototype staff-facing and use synthetic case information for the hackathon.
- Defer the five workflow screens until the front-page visual language is selected. Explore twenty distinct front-page concepts first to avoid spreading an untested style across the product.
- Use one flat Base44 import table with one row per service: 220 public service records plus 6 clearly marked fictional demo providers. Keep aggregate projects, cases, evidence events, and schemas out of the service entity because they are different record types.
